Cinema FMI - REST API (partea a doua)

Cererile GET pot fi deschise direct din browser:

  • GET /api/movies
  • GET /api/movies?page=0&size=2
  • GET /api/movies/1
  • GET /api/movies/1/screenings
  • GET /api/movies/1/screenings/2

Headerele raspunsului se vad in browser cu F12 → Network → cererea → Headers.

Pentru PATCH, POST si DELETE folositi fisierul requests.http din IntelliJ.
